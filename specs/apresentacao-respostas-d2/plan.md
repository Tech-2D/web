# Plano

Interpretar Markdown no portal e formatar o texto de Notas do contrato já publicado. Manter os cartões existentes da Agenda e do Kanban. Verificar a apresentação da consulta, o Markdown, os links e a revelação das respostas simples.

Aplicar a largura à resposta de Notas e usar CSS para a entrada dos blocos. O estado do chat identifica a resposta que chegou enquanto o painel estava visível. Os dados entram juntos no DOM para leitores de tela.
